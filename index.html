Las 3 Afirmaciones Fundamentales

📦

Stock Consistente

El stock que muestra el catálogo es exactamente el stock real disponible. Ningún producto puede tener existencias negativas gracias a controles en dominio y restricciones CHECK a nivel de motor.

🔒

Ventas Inmutables

Toda venta registrada es permanente. El precio y el nombre del producto se congelan en el momento exacto de la transacción para garantizar trazabilidad y auditoría sin alteraciones.

📊

Reportes Inalterables

El reporte de un período cerrado dirá exactamente lo mismo hoy y dentro de diez años, consolidando las ventas mediante el motor de base de datos sin depender de variaciones del catálogo vivo.

Diseño Basado en Arquitectura Onion

1. Dominio Puro

Entidades y Value Objects puros sin dependencia de frameworks ni librerías de persistencia externa.

2. Aplicación

Casos de uso orquestadores con puertos entrantes y salientes y manejo transaccional Unit of Work.

3. Infraestructura

Persistencia Eloquent ORM con mappers aislados, concurrencia optimista y seguridad JWT.

4. Presentación

Controladores HTTP, validación de forma y serialización de errores bajo el estándar RFC 7807 Problem Details.
